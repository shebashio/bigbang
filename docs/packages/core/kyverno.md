# Kyverno Package Boundaries

The [Kyverno engine draft guide](https://repo1.dso.mil/big-bang/product/packages/kyverno/-/blob/44642cd53a556731f091d4560d5a0ca2788d9fe4/docs/overview.md) covers the controller, CRDs, webhooks, mesh integration, metrics, and engine configuration.

Kyverno Policies and Kyverno Reporter are separately versioned packages and remain documented by their respective owners. Their release ordering and other umbrella orchestration remain Big Bang concerns.
